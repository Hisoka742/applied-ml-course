# ДЗ #1. Дообучение с итеративной аугментацией, разморозкой слоёв и псевдолейблингом

Найти и согласовать с преподавателем датасет. Обучить как минимум 2 разных архитектуры сетей, используя
разобранные на занятии техники:

- итеративная аугментация;
- итеративная разморозка слоёв с адаптивным lr;
- псевдолейблинг.

**Датасет:** EuroSAT RGB (27 000 спутниковых снимков 64×64, 10 классов), согласован с преподавателем.
Разметка оставлена у 10% обучающей выборки, остальное — неразмеченный пул для псевдолейблинга.

**Архитектуры:** ConvNeXt-T и DeiT-S (предобучены на ImageNet, `timm`).

**Решение:** [hw1_finetuning_pseudolabeling.ipynb](hw1_finetuning_pseudolabeling.ipynb).

## Структура

| Файл | Содержимое |
|------|------------|
| `eurosat_ssl/data.py` | загрузка EuroSAT, разбиение на размеченную / неразмеченную / val / test части |
| `eurosat_ssl/augmentations.py` | уровни аугментаций для итеративной аугментации, TTA |
| `eurosat_ssl/models.py` | модели и группы слоёв для итеративной разморозки |
| `eurosat_ssl/training.py` | обучение по стадиям: разморозка, дискриминативный и адаптивный lr, ранняя остановка |
| `eurosat_ssl/pseudo_labeling.py` | отбор псевдометок и раунды self-training |
| `eurosat_ssl/experiments.py` | сборка датасетов для экспериментов и метрики |
| `eurosat_ssl/plotting.py` | одинаковый отчёт для каждого запуска: кривые обучения и матрица ошибок |
| `tests/` | тесты |

## Запуск

Обучение рассчитано на GPU, полный прогон ноутбука на GPU Kaggle занял около часа (≈62 минуты чистого обучения).

**Kaggle или Colab.** Загрузить `hw1_finetuning_pseudolabeling.ipynb`, включить GPU и интернет, запустить все
ячейки. Первая ячейка сама клонирует код из этой ветки репозитория, датасет скачивается автоматически.

**Локально** (из папки `hw1_finetuning_pseudolabeling`):

```bash
pip install -r ../requirements.txt
python -m pytest                       # tests, CPU only
jupyter lab hw1_finetuning_pseudolabeling.ipynb
```

Быстрая проверка, что весь ноутбук отрабатывает (подвыборка 2000 снимков и по 1 эпохе на стадию, CPU):

```bash
SMOKE_TEST=1 jupyter nbconvert --to notebook --execute --output smoke_run.ipynb hw1_finetuning_pseudolabeling.ipynb
```

Датасет (~90 МБ) скачивается в `data/` и в репозиторий не попадает. Чекпоинты моделей не сохраняются:
лучшие веса держатся в памяти на время прогона.
