# Прикладные задачи машинного обучения

Решения домашних заданий курса. Каждое ДЗ живёт в отдельной ветке, отходящей
от `main`, и сдаётся через Pull Request в `main`.

| ДЗ | Ветка | Решение |
|----|-------|---------|
| ДЗ #1 | `hw1_finetuning_pseudolabeling` | [hw1_finetuning_pseudolabeling/](hw1_finetuning_pseudolabeling/) *(в работе: ждём согласования датасета)* |
| ДЗ #2 | `hw2_crowd_aggregation` | [hw2_crowd_aggregation/](hw2_crowd_aggregation/) |

## ДЗ #1

Найти и согласовать с преподавателем датасет.
Обучить как минимум 2 разных архитектуры сетей, использовать разобранные на
занятии техники:

- Итеративная аугментация
- Итеративная разморозка слоев с адаптивным lr
- Псевдолейблинг

## ДЗ #2

Сгенерировать или найти датасет асессорских оценок, посчитать по нему разные
статистики и описать, почему они похожи на реальные данные.
Применить методы агрегации:

- Majority Vote
- Weighted Majority Vote
- Dawid-Skene

Замерить качество, сделать выводы.

## Окружение

```bash
python -m venv .venv
.venv/Scripts/activate        # Windows; on Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Инструкции по запуску конкретного ДЗ лежат в README внутри его папки.
